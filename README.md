# 🎉 Eid Greeting - موقع تهنئة العيد التفاعلي الفاخر مع لوحة التحكم الآمنة

موقع تهنئة فخم، حديث وتفاعلي بمناسبة العيد المبارك، مصمم بأسلوب **Glassmorphism** مع مظهر زمردي وذهبي جذاب (Dark Emerald & Gold). يسمح الموقع للزوار بتخصيص كروت تهنئة بأسمائهم ومشاركتها مباشرة عبر واتساب أو نسخ الرابط، مع تتبع آمن وإحصائي كامل لكل زائر وحفظ البيانات بشكل مشفر وحصري في قاعدة بيانات Supabase.

---

## ✨ المميزات الحديثة للتطوير الشامل

1. **الجمالية الفائقة (Premium UI/UX):** تصميم زجاجي بلوري داكن متناسق مع خطوط عربية فاخرة (Cairo & Amiri) ومؤثرات حركية خفيفة (فوانيس متأرجحة وبريق النجوم).
2. **التفاعل الفيروسي (Viral Features):** مولد كروت تهنئة متطور حيث يدخل المستخدم اسمه، فيحصل على كارت فوري مخصص ورابط فريد لمشاركته مع العائلة والأصدقاء. عند فتح الرابط، يقرأ النظام اسم المرسل ويعرض التهنئة مخصصة باسمه!
3. **أمان وحماية الخصوصية 100%:** 
   - تم تفعيل **Row Level Security (RLS)** لحماية بيانات الزوار.
   - إلغاء القراءة المباشرة من المتصفح (REVOKE SELECT) لمنع سرقة أو تسريب عناوين الـ IP الخاصة بالزوار.
   - إعداد دالة برمجية آمنة ومحمية بقاعدة البيانات **(Secure RPC Function)** باسم `get_visitors(auth_pass)` بجانب كلمة المرور الحصرية `eid2026`.
4. **لوحة تحكم إحصائية متكاملة (Interactive Dashboard):** مدمجة بالكامل مع مكتبة **Chart.js** لعرض:
   - رسم بياني للنشاط ومعدل الزيارات اليومية.
   - رسم بياني لأكثر الدول زيارة.
   - رسم بياني لتوزيع الأجهزة المستخدمة.
   - فلاتر متقدمة للتصفية بالدولة، نوع الجهاز، والتاريخ.

## 🚀 إرشادات الإعداد والتشغيل

### 1. إعداد قاعدة البيانات (Supabase Setup)

1. توجه إلى حسابك في [supabase.com](https://supabase.com).
2. أنشئ مشروعاً جديداً أو ادخل إلى مشروعك الحالي.
3. اذهب إلى **SQL Editor**، وافتح سكريبت جديد وقم بلصق محتوى ملف `supabase/schema.sql` بالكامل وتشغيله (Run). سيقوم السكريبت بـ:
   - إنشاء جدول الزوار `visitors`.
   - تفعيل نظام الحماية RLS وسياسة الإدخال الآمن للمجهول.
   - إعداد الصلاحيات للـ Sequence لتفادي أخطاء الإدخال التلقائي للـ ID.
   - إنشاء دالة الـ RPC المشفرة بكلمة المرور `eid2026` لقراءة البيانات.

### 2. مفاتيح الربط البرمجي (API Connection Keys)

* الموقع مهيأ افتراضياً للعمل وتجربة الإرسال على خادم Supabase التجريبي.
* إذا أردت استخدام خادمك الخاص، قم بتحديث المتغيرات التالية في ملف `script.js` (السطر 5 و 6) وفي `dashboard.html` (السطر 173 و 174):
  - `SUPABASE_URL`: رابط مشروعك الخاص.
  - `SUPABASE_ANON_KEY` / `SUPABASE_KEY`: مفتاح الـ Anon الخاص بمشروعك.

### 3. التتبع الجغرافي (Geolocation API)

* يعمل التتبع تلقائياً ودون الحاجة لأي إعدادات إضافية أو مفاتيح اشتراك مدفوعة! 
* يعتمد النظام على واجهات مجانية مفتوحة المصدر (`api.ipify.org` و `get.geojs.io`) لاستخلاص عناوين الـ IP والموقع الجغرافي (الدولة، المدينة، الإحداثيات) بشكل آمن وسريع وصامت دون إعاقة سرعة تحميل الصفحة للزائر.

### 4. النشر والتشغيل (Deployment)

لرفع الموقع وتشغيله على الإنترنت مجاناً:
1. ارفع ملفات المشروع (`index.html` و `style.css` و `script.js` و `dashboard.html`) إلى مستودع (Repo) جديد على GitHub باسم `eid-greeting`.
2. اذهب إلى **Settings > Pages** للمستودع على GitHub.
3. اختر مصدر النشر (Source) ليكون الـ `main` branch واضغط Save.
4. سيتم نشر موقعك ويكون جاهزاً للزيارة والمشاركة على الرابط: `https://[username].github.io/eid-greeting/`.
5. للوصول للوحة التحكم، توجه للرابط: `https://[username].github.io/eid-greeting/dashboard.html` وادخل كلمة المرور `eid2026`.

## 🔒 حماية وخصوصية البيانات المدخلة

تم إلغاء صلاحية الوصول المباشر (Select) لجدول الزوار بالكامل للمستخدمين المجهولين عبر بروتوكول الـ API لـ Supabase. ولا يمكن تحت أي ظرف جلب قائمة الزوار إلا بتمرير كلمة المرور الصحيحة `eid2026` إلى خادم قاعدة البيانات لتشغيل دالة الـ RPC الآمنة التي تتحقق من صحة الرقم السري على مستوى السيرفر قبل إعادة أي معلومات، مما يضمن أماناً أقصى وخصوصية تامة لجميع زوار موقعك.
